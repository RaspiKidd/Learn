## Training Programme Overview

- **Duration:** 3 hours
- **Target Audience:** Librarians (mixed experience levels)
- **End Goal:** Confident, independent delivery of Scratch code clubs

## Learning Objectives

By the end of this training, you will be able to:

- ✅ Navigate Scratch confidently and explain basic programming concepts to children
- ✅ Run engaging 60-minute code club sessions with clear structure and flow
- ✅ Troubleshoot common technical and learning challenges that arise during sessions
- ✅ Adapt activities for different skill levels and equipment setups
- ✅ Manage a group of young coders effectively in a library environment
