**Scratch** is a free visual programming language developed by MIT, specifically designed for children and beginners.

## Key Features

- **Visual blocks** instead of text-based coding
- **Drag and drop** interface - no typing required
- **Immediate results** - see your code in action instantly
- **Creative focus** - make games, animations, stories, and interactive art
- **Cross-platform** - works on computers, tablets, and Chromebooks

## Why Scratch is Perfect for Libraries

- **Free** - no licensing costs
- **Web-based** - no software installation required
- **Safe** - moderated online community
- **Educational** - teaches computational thinking
- **Inclusive** - works for all skill levels
- **Website:** [scratch.mit.edu](https://scratch.mit.edu/)
